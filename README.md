# Aulas LP2 (2026)

Repositório destinado aos códigos e exemplos práticos da disciplina de Laboratório de Programação 2 (turma de 2026) do curso de Informática.

## Estrutura do Repositório

O conteúdo está organizado por tópicos de JavaScript e desenvolvimento web:


* `javascript-arrays-objetos/`: Manipulação de vetores, estruturas de dados e objetos em JavaScript.
*  `javascript-funcoes/`: Declaração de funções, parâmetros, retornos e modularização de código.
* `javascript-dom/`: Manipulação da árvore de elementos do DOM, eventos e integração com APIs.
* `media-query/`: Exemplos de media queries.
